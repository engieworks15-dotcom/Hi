3. LAN Chat

Functional prototype
Fields: Computer networking, software engineering, distributed communication.


LAN Chat is a local-network communication application designed to enable messaging between devices connected to the same local area network without requiring an external internet connection.

The project explores how devices can establish communication over existing network infrastructure and exchange messages locally. It investigates fundamental networking concepts, including device connectivity, message transmission and communication between software clients.

Its motivation is to explore alternatives to internet-dependent messaging in environments where connectivity may be unreliable or unavailable.

Verified progress: Devices can successfully exchange messages through the application.

Next development priorities:
- Improve the messaging interface.
- Investigate multi-device communication.
- Improve message handling and reliability.
- Explore user identification and conversation management.
- Test performance under different local-network conditions.
